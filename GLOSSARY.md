# Deadlock TH

A Thai-language guide to the game Deadlock, written to be short and easy to understand, translated from the community wiki (deadlock.wiki).

## Language

### Site

**Tab**:
A top-level part of the site covering one subject: Commands, Items, Heroes, Patch notes. A tab appears in the site menu only once it has a real page.
_Avoid_: section (used for parts of a page), category

**Hero**:
A playable character in Deadlock, named as in the game.
_Avoid_: character, ตัวละคร, champion

**Patch notes**:
Valve's published list of changes for a game update, which this site translates.
_Avoid_: changelog, update log

### Commands

**Console command**:
A line typed into Deadlock's developer console (opened with F7) to change a setting or trigger an action. Its name and values are copied exactly from the source and never translated.
_Avoid_: cheat code, คำสั่งโกง

**Cheat command**:
A console command that only works when cheats are enabled (`sv_cheats true`), so it never works in a normal multiplayer match.
_Avoid_: dev command, admin command

**Bind**:
A console command that ties a key to one or more other console commands, so pressing the key runs them (e.g. `bind m "toggle volume 0 0.5"`).
_Avoid_: hotkey, macro, keybind setting (the in-game settings menu)

**Command group**:
A purpose-based grouping of console commands, such as practice, bots/NPCs, map/lobby or HUD/info. This site defines the groups; the wiki only lists commands alphabetically.
_Avoid_: category (the wiki uses "category" for its own page categories)

### Content

**Source**:
A published page that this site takes content from, pinned to the revision that was used. The primary source is deadlock.wiki; the Valve Developer Wiki command list is a secondary source. Every piece of content shows which source it came from, or that the site wrote it itself.
_Avoid_: reference, original

**Translation**:
The Thai rendering of a source's explanatory text. It states what the source says, shortened, and adds nothing.
_Avoid_: summary

**Untested**:
The status of a command or bind that the site has not yet confirmed works in the current game. It applies to everything taken from the secondary source or written by the site, until it has been tried in-game.
_Avoid_: unverified, beta

**Practice note**:
Advice that this site adds on how a command helps you practise. It is not from the source page and is always shown apart from the translation.
_Avoid_: tip (ambiguous with in-game tips)

**Game term**:
A word that appears in the game's own English UI, such as Trooper, Hideout, Sandbox or Flex slot. It stays in English so it matches what the player sees in the game.
_Avoid_: ทับศัพท์ (Thai transliterations) of these words
