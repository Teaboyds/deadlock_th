The following is a list of  Deadlock console commands and variables listed in alphabetical order.

Todo: Per-user convar defaults haven't been documented here since they might not reflect the true defaults.

Notes

Note: Retrieved April 12, 2026 Build: 10725 (revision 10589924)
Note: Deadlock does not print the actual cvar list using Cvarlist when using the launch option -Condebug like previous games did. Plus, using Cvarlist lists all commands from Z up to the middle of letter C, due to the limit of lines the console can show ingame. Therefore this list was made using incremental uses of Cvarlist, followed by Cvarlist <character> to get anything that may have been missed, then stitching all of it together. Additionally, Cvarlist log <logname> was also used to retrieve commands.
Note: Some commands shown on this list may be removed or hidden when the game receives new updates.
